# Тестирование API веб-приложения Яндекс Прилавок

Примеры тестирования API сервиса доставки: коллекция запросов Postman и тестовая документация.

## Состав проекта

| Файл | Содержание |
|---|---|
| `api-testing.postman_collection.json` | Коллекция запросов Postman для проверки расчёта доставки, работы с корзиной, создания набора и пользователя |
| [`api_checklist_and_bugreport.xlsx`](https://docs.google.com/spreadsheets/d/1tpiiOM2OIE2_wWQBdVRLVA8jChrT_8X83pkQJLnrHBE/edit?usp=sharing) | Примеры тестовой документации |

## Область проверок

Коллекция Postman включает 10 запросов:

- **Расчёт доставки** — запросы с XML-телом для проверки корректных данных и значений параметров `deliveryTime`, `productsCount`, `productsWeight`.
- **Работа с корзиной** — получение корзины, добавление товаров, создание и удаление корзины.
- **Создание набора** — POST-запрос с Bearer Token.
- **Создание пользователя** — POST-запрос с JSON-телом.

В запросах используются HTTP-методы GET, POST, PUT и DELETE, а также форматы JSON и XML.

## Используемые инструменты и технологии

- **Postman** — подготовка и отправка API-запросов;
- **HTTP** — методы GET, POST, PUT, DELETE;
- **JSON и XML** — форматы данных запросов;
- **Bearer Token** — авторизация запроса создания набора.
