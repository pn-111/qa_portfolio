## Стек технологий

**Документация и ручное тестирование:** Google Sheets, Markdown, Postman.
**Базы данных:** SQLite, VS Code (расширение SQLite).
**Автоматизация:** Python 3.x, Playwright, Pytest, Requests, паттерн проектирования Page Object Model (POM).
**Окружение:** Windows 10 (21H2), Firefox / Яндекс Браузер, разрешение 1920x1080.
**Методы тест-дизайна:** классы эквивалентности, анализ граничных значений, позитивное и негативное тестирование.

## Ручное тестирование

### Веб-приложение (Яндекс Маршруты)

Проверка формы добавления водительских прав и смежных сценариев.

**Материалы:** [Google Sheets — тест-кейсы и баг-репорты](https://docs.google.com/spreadsheets/d/1mOQd9REpLdHbpGupaeqBWLjayFL7ndrWHSQuLmb5nD8/edit?usp=sharing)

**Что сделано:**
- Позитивные и негативные тест-кейсы для полей «Имя», «Фамилия», «Дата рождения», «Номер».
- Проверка граничных значений и валидации.
- Баг-репорты (включая дефекты уровня Blocker: кнопка «Отмена» инициирует сохранение вместо отмены).

**Инструменты:** Google Sheets, Markdown.

### API (Яндекс Прилавок)

Тестирование сервиса доставки: расчёт доставки, работа с корзиной, создание набора и пользователя.

**Материалы:**
- [Postman-коллекция](./api-testing/Sergey%20Podkorytov%207%20sprint.postman_collection.json)
- [Google Sheets — чек-лист и баг-репорты](https://docs.google.com/spreadsheets/d/1tpiiOM2OIE2_wWQBdVRLVA8jChrT_8X83pkQJLnrHBE/edit?usp=sharing)

**Область проверок:**
- Расчёт доставки: XML-тело, параметры `deliveryTime`, `productsCount`, `productsWeight`.
- Работа с корзиной: получение, добавление товаров, создание и удаление корзины.
- Создание набора (POST + Bearer Token) и пользователя (POST + JSON).

**Инструменты:** Postman, HTTP (GET, POST, PUT, DELETE), JSON, XML, Bearer Token.

## Работа с базами данных (SQL)

Демонстрация навыков написания запросов для верификации данных и поиска аномалий на примере сервиса каршеринга.

**Файлы:**
- [`schema.sql`](./sql/schema.sql) — создание таблиц (`users`, `licenses`, `cars`, `rides`) с ограничениями (`NOT NULL`, `UNIQUE`, `DEFAULT`, `REFERENCES`) и наполнение тестовыми данными.
- [`queries.sql`](./sql/queries.sql) — проверочные запросы.

**Реализованные проверки:**
- Выборка данных по условию (`SELECT`, `WHERE`).
- Проверка связей между таблицами (`JOIN`).
- Агрегация и группировка (`GROUP BY`, `COUNT`, `HAVING`).
- Поиск пользователей без зарегистрированных водительских прав (LEFT JOIN + IS NULL).
- Поиск логических и финансовых аномалий (поездки с `end_time < start_time`, поездки с `cost <= 0`).

**СУБД:** SQLite.

## Автоматизация тестирования

Код автотестов вынесен в отдельные репозитории для чистоты архитектуры.

### UI-автотесты (SauceDemo)

Автоматизация тестирования веб-приложения [SauceDemo](https://www.saucedemo.com/).

- **Стек:** Python 3.x, Playwright, Pytest, паттерн проектирования Page Object Model (POM).
- **Структура:** `pages/` (Page Object), `tests/` (тесты), `conftest.py` (фикстуры), `requirements.txt`.
- **Запуск:** `pip install -r requirements.txt`, `playwright install`, `pytest`.

🔗 [Перейти в репозиторий `saucedemo-ui-autotests`](https://github.com/pn-111/saucedemo-ui-autotests)

### API-автотесты (Яндекс Прилавок)

Автоматизированная проверка API Яндекс.Прилавка (валидация параметра `firstName` при создании пользователя).

- **Стек:** Python 3.x, Requests, Pytest.
- **Структура:** `configuration.py` (конфигурация), `data.py` (тестовые данные), `sender_stand_request.py` (отправка запросов), `create_user_test.py` (тесты).
- **Запуск:** `pip install pytest requests`, затем `pytest`.

🔗 [Перейти в репозиторий `yandex_api_stand_tests`](https://github.com/pn-111/yandex_api_stand_tests)
