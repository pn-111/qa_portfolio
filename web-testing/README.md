# Тестирование веб-приложения Яндекс Маршруты

Примеры тестовой документации по ручному тестированию веб-приложения «Яндекс Маршруты».

## Содержание

Материалы собраны в файле [`web_testcase_andbugreport`](https://docs.google.com/spreadsheets/d/1mOQd9REpLdHbpGupaeqBWLjayFL7ndrWHSQuLmb5nD8/edit?usp=sharing), который содержит следующие листы:

*   **Тест-кейсы:** Проверка формы добавления водительских прав.
*   **Баг-репорты:** Найденные дефекты. 

## Инструменты и технологии
*   **Документация:** Google Sheets, Markdown.
*   **API-тестирование:** Postman (отправка XML-запросов, проверка HTTP-статусов).
*   **Окружение:** Windows 10, Firefox, разрешение 1920x1080.
*   **Методы тест-дизайна:** Классы эквивалентности, анализ граничных значений, позитивное и негативное тестирование.
